# Pinterest Interest Application

This is a website showcasing my interest in Pinterest. It contains a collection of hand-drawn assets, animated assets, and a mix between online and self-produced sound effects. Made using Procreate, Audacity, Figma, with inspiration from Claude Design (Classical Mode).

## Preview locally
From this folder run:
```
npx serve .
```
or `python3 -m http.server`, then open the printed localhost URL. In VS Code, the "Live Server" extension also works.

## Files
- index.html — the page (markup + logic)
- support.js — small runtime the page needs to render
- paper-engine-global.js — generates the paper grain, creases and blue ruling
- assets/ — font, tape pieces, icons, intro frames (assets/intro), sound effects
- ds/ — base stylesheet
